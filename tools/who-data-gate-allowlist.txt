# who-data-gate allowlist  (see THE RULE FOR THIS FILE below before adding anything)
#
# Lines are '#'-commented. Section headers switch mode:
#   [allow-literal]  exact tokens (case-insensitive) that are genuine, NON-WHO
#                    false positives and should pass everywhere (now and future).
#   [allow-regex]    Python regexes; a matched token passes if it fullmatch()es one.
#   [skip-path]      fnmatch globs of paths that are NOT scanned at all.
#
# For already-public tokens that merely need grandfathering, do NOT list them here —
# they live (as hashes, no plaintext) in who-data-gate-baseline.txt. Regenerate that
# with:  tools/who-data-gate.py --update-baseline
#
# THE RULE FOR THIS FILE. Entries are PERMANENT and apply everywhere, so only two
# kinds of token belong here:
#   (a) invented placeholders (EXAMPLE..., LOC, OTHER, LAB 0000-000, J/O residues), and
#   (b) nomenclature that is published and can never become pre-publication - clade
#       DESIGNATIONS, which are public by definition (WHO / nextclade /
#       influenza-clade-nomenclature), listed individually so that a NEW clade token
#       still fails the gate.
# A real STRAIN NAME never belongs here, however long it has been published: this file
# is not scoped to a path, so one line would pass that name everywhere, forever. Real
# names that are genuinely already public in the tree go in who-data-gate-baseline.txt,
# where they are stored as hashes and are scoped to the one file that contains them.
#
# Hex colour codes (#rrggbb) and 0x.. literals are masked automatically before the
# rules run, so they need no entry here.

# Reserved SYNTHETIC location namespace for docs/examples/fixtures: any location of the
# form EXAMPLE… (single word; or B-initial "BEXAMPLE…" where an example must start
# with B). Use these when writing new placeholder strain names — never invent
# a plausible real city. Matches with or without an A/, B/ or A(H3N2)/ subtype prefix.
(?:[AB](?:\([^)]*\))?/)?B?EXAMPLE[A-Z]*/[0-9]+/(?:19|20)?[0-9]{2}
# The same namespace in the underscore forms tree leaves use (a space written as '_',
# a '_' inside the isolate): every alphabetic part must itself start with EXAMPLE, so a
# real place or isolate can't match. E.g. EXAMPLETOWN_EXAMPLEISLES/EXAMPLE_6/2026.
(?:[AB](?:\([^)]*\))?/)?B?EXAMPLE[A-Z]*(?:_EXAMPLE[A-Z]*)*/(?:[0-9]+|EXAMPLE[A-Z0-9]*)(?:_[0-9]+)?/(?:19|20)?[0-9]{2}
# Synthetic placeholder serum ids used in format docs/examples (LAB 0000-000 style):

# Synthetic AA substitutions for tests/examples. `J` and `O` are NOT amino-acid codes
# (no sequence or transition can contain them), so this pattern can never mask real data.
# Use these residues when a test needs an invented substitution.
